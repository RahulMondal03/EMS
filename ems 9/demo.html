1 · How it's built

Every page is an HTML file with one small script. They all share a single data object, so the whole app works without a server.

📄 Pages

customer/, employee/ and admin/ hold 20 screens. Each page.html has a matching js/<folder>/page.js.

🧠 js/data.js

The EMS object holds customers, staff, tariffs, bills, complaints and payments, plus every function that changes them. Data persists in localStorage.

🧭 js/chrome.js

Builds the staff menu from the signed-in employee's position and adds the footer, so each person only sees the links they're allowed to.

Page loads→ EMS.requireRole / requirePerm→ Read from EMS→ Build rows as HTML→ Save back to localStorage

2 · One employee role, three positions

There's no separate admin login. An employee's position decides their capabilities, and the menu, page guards and buttons all read from them.
